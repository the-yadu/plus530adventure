# Plus530 Adventure

A modern, premium website for Plus530 Adventure - an overlanding and self-drive travel company specializing in Himalayan expeditions.

## Features

- **Modern Tech Stack**: Built with Next.js 14 (App Router), TypeScript, and Tailwind CSS
- **Dynamic Routes**: Dynamic adventure pages with detailed itineraries
- **Blog System**: Markdown-based blog with multiple posts
- **Responsive Design**: Fully responsive across all devices
- **SEO Optimized**: Meta tags, Open Graph, and structured data
- **Premium UI**: Clean, adventure-focused design with smooth animations

## Pages

- **Home**: Hero section, featured adventures, services, gallery, and newsletter signup
- **Adventures**: Browse all adventures with dynamic routing to individual adventure pages
- **About**: Company story, values, and team
- **Blog**: Adventure stories and travel tips with Markdown support
- **Contact**: Contact form with company information

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.

## Technologies Used

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- React Markdown
- Gray Matter
- Lucide React (Icons)
